# React Admin Dashboard

A modern and responsive **Admin Dashboard** built with React.js and Vite. This application brings essential management tools together in one place, including project tracking, analytics, calendar management, contact organization, and team communication.

The goal is to build a practical dashboard experience while exploring reusable React components, state management, API integration, and real-world frontend development practices.

## ✨ Features

### 📊 Dashboard
- Centralized overview of the application.
- Quick access to important sections.
- Organized interface for management activities.

### 📁 Project Management
- Dedicated project management section.
- Project tracking and organization.
- Designed to support project-related workflows.

### 📈 Analytics
- Dedicated analytics section.
- Overview of relevant application data.
- A foundation for data visualization and reporting.

### 📅 Calendar
- Calendar management interface.
- Organized view of important dates and events.

### 👥 Contact Management
- Contact directory with profile information.
- Contact cards with names and company details.
- Interactive contact actions.
- Contact search and management interface.

### 💬 Team Messages
- Dedicated team messaging section.
- Interface for organizing team communication.

## ⚙️ Requirements

Before running the project, make sure you have:

- [Node.js](https://nodejs.org/) 20.19+ or 22.12+
- npm (included with Node.js)
- Git

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd react-admin-dashboard
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

## 🏗️ Production Build

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
